# 📖 Overview

The **T2Drive Admin Portal** is the operational backbone of the T2Drive mobility platform. It enables administrators to manage drivers, customers, pricing, trips, subscriptions, payments, support operations, and platform configuration through a centralized dashboard with real-time updates.

The portal is designed with a scalable **Role-Based Access Control (RBAC)** architecture, ensuring secure access to operational modules while supporting enterprise-grade administration.
